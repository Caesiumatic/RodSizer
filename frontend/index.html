RodSizer

Detects, sizes, and analyzes gold nanorods.

About This App

RodSizer detects, separates, measures, and analyzes gold nanorods in electron-microscopy (TEM / STEM / SEM) images — running entirely on your own computer.

How it works: particles are segmented with K-means thresholding; touching or overlapping rods are split with a distance-transform watershed; and each particle is measured from a rotated bounding box (length, width, aspect ratio, area, volume, and shape descriptors).

Calibration: pixel size is read from embedded metadata (DM3/DM4, EMD, TIFF) or, for camera exports, from the burned-in scale bar / footer via on-image OCR. Manual calibration is always available.

Methodology: based on JACS Au 2021, 1, 316−327 (AutoDetect-mNP), extended with watershed clump-splitting and OCR calibration.

Developed by Arda Turk and Shi Chen in Murphy's Group @ UIUC, with assistance from Claude & ChatGPT.

Upload Instructions

You can upload multiple images at once. Detection runs automatically in the background after upload.

Supported image formats: TIFF (.tif/.tiff), PNG, JPG/JPEG

Supported metadata formats: .dm3, .dm4, .emd

How the scale (pixel size) is found, in order:

  • .dm3/.dm4/.emd & tagged TIFF: read automatically from embedded metadata.
  • Camera exports (PNG/JPG/TIFF without metadata): read automatically from the burned-in scale bar or the "Pixel size / Fov" footer via OCR.
  • Anything else: calibrate manually on the analysis page (draw a line along the scale bar and type its length).

Have a separate metadata file (.dm3/.dm4/.emd)? Upload it with the same filename as the image and it will be linked automatically.

On the analysis page you can: click a particle to exclude it, sort the table by size, bulk select/deselect above or below a row, auto-remove statistical outliers, and toggle the ID labels.

Note: Please open and review each image individually to verify detection (and confirm the scale) before viewing the Folder Analysis.
